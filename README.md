# Sena — Ruang Teduh

Link in bio guru mindfulness & teh, Sena: kelas, retret, dan tulisan dalam satu ruang yang tenang.

**Demo live:** https://linkinbio-zen.vercel.app

![Tangkapan layar Sena](public/og.jpg)

> Template link-in-bio dengan persona fiktif.

## Konsep

Persona Sena, mindfulness dan teh. Minimal serif dengan lingkaran enso yang bernapas, daftar angka Romawi, dan benang vertikal.

## Halaman

`/`

## Teknologi

- Next.js 15.5 (App Router) dan React 19
- Tailwind CSS v4
- JavaScript
- Lucide (ikon)
- Font: Cormorant Garamond, Inter (next/font)
- SEO: metadata per halaman, Open Graph, JSON-LD, sitemap.xml, dan robots.txt

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000. Untuk build produksi: `npm run build` lalu `npm start`.
